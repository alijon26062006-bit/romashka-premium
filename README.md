# 🌼 Ромашка Premium — интернет-магазин цветов

Готовый коммерческий магазин цветов: премиальная витрина, корзина, оформление заказа через WhatsApp и админ-панель, в которой владелец сам добавляет букеты — без программиста.

- **Витрина** — каталог, категории, поиск, карточка букета, корзина
- **Заказы** — уходят в WhatsApp и одновременно сохраняются в панели как заявки
- **Админка** — добавление букетов за минуту, загрузка фото перетаскиванием, настройки магазина
- **Готово к серверу** — Docker, автоматический SSL, запуск одной командой

---

## Запуск на сервере одной командой

Нужен любой VPS с Ubuntu и купленный домен, у которого A-запись указывает на IP сервера.

```bash
git clone https://github.com/ВАШ-АККАУНТ/romashka.git
cd romashka
chmod +x deploy.sh
./deploy.sh ваш-домен.tj
```

Скрипт сам:
1. установит Docker, если его нет;
2. создаст `.env` со **случайным паролем администратора**;
3. соберёт и запустит проект;
4. получит бесплатный SSL-сертификат Let's Encrypt (сайт сразу откроется по `https://`);
5. напечатает адрес сайта, логин и пароль.

Без домена — просто `./deploy.sh`, сайт откроется по IP сервера.

### Обновление после правок

```bash
git pull && ./deploy.sh ваш-домен.tj
```

Каталог, настройки и загруженные фото хранятся в папках `data/` и `uploads/` и переживают любое обновление.

### Полезные команды

```bash
docker compose logs -f      # смотреть логи
docker compose restart      # перезапустить
docker compose down         # остановить
```

## Локальный запуск (Windows / macOS / Linux)

```bash
npm install
npm start
```

- Сайт: http://localhost:3000
- Админка: http://localhost:3000/admin.html
- Логин `admin`, пароль `admin123` — **только для локальной работы**

Для разработки: `npm run dev` — сервер перезапускается сам при правке файлов.

## Настройка перед публикацией

Все секреты лежат в файле `.env` (в git он не попадает). Скопируйте образец и заполните:

```bash
cp .env.example .env
```

| Переменная | Зачем нужна |
|---|---|
| `ADMIN_PASSWORD` | Пароль в админку. **Обязательно поменяйте** |
| `SITE_URL` | Ваш домен с `https://` — для ссылок в Google и превью в WhatsApp |
| `DOMAIN` | Домен для автоматического SSL в Docker |
| `PORT` | Порт сервера, по умолчанию 3000 |

Название магазина, номер WhatsApp, телефон, часы работы и город меняются **прямо в админке**, в разделе «Настройки» — трогать код не нужно.

## Админ-панель

### Товары
- Добавление букета: обязательны только **название, цена и фото**
- До 5 фотографий: перетащите в форму, выберите файлом или вставьте из буфера (Ctrl+V)
- Быстрые кнопки-подсказки для состава, повода, цвета и размера — заполнение в один клик
- Старая цена — показывается зачёркнутой рядом с новой
- Прямо из карточки: `Скрыть` / `В наличии`, `В хиты`, `Копия`, `Изменить`, `Удалить`
- Кнопка **Копия** дублирует букет — удобно, когда композиции похожи
- Поиск и фильтры по категории и наличию

### Заявки
Каждое оформление заказа из корзины сохраняется здесь: состав, сумма, дата. Статусы «Новая», «Обработана», «Отменена».

### Настройки
Название, WhatsApp, телефон, часы, город, валюта, Instagram, Telegram и описание сайта для поисковиков.

## Безопасность

- Пароль администратора хранится в `.env`, а не в коде
- Вход выдаёт временный токен сессии на 12 часов
- Защита от подбора пароля: 10 попыток за 15 минут с одного адреса
- Все поля товара проверяются на сервере, ссылки на фото — только `http(s)` и свои загрузки
- Заголовки безопасности и Content-Security-Policy включены
- Запись каталога атомарная — сбой сервера не повредит данные

---

## Производительность

- Ответы сжимаются gzip/brotli
- Фотографии кэшируются на год, статика — на неделю
- Главная страница грузит всё одним запросом `/api/bootstrap`
- В сетке каталога подгружаются уменьшенные версии фото
- Ссылки на букеты отдают превью с фото и ценой при отправке в WhatsApp
