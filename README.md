# Ромашка Premium

Премиальный интернет-магазин цветов на Node.js + Express.

## Что готово

- Премиальный дизайн главной страницы в стиле предоставленных референсов.
- Адаптивная версия для desktop / tablet / mobile.
- Категории с изображениями и фильтрацией каталога.
- Карточки товаров с быстрым добавлением в корзину.
- Полноценная боковая корзина с количеством, удалением и итоговой суммой.
- Оформление заказа через WhatsApp с автоматически сформированным сообщением.
- Поиск по каталогу.
- Отдельная страница товара.
- Плавающая кнопка WhatsApp.
- Премиальная админ-панель: статистика, добавление, редактирование, удаление товаров и загрузка изображений.
- Сохранение товаров в `data/products.json`.
- Загрузка JPG / PNG / WEBP до 8 МБ.
- Существующий backend/API сохранён.

## Запуск

```bash
npm install
npm start
```

Сайт: `http://localhost:3000`  
Админ-панель: `http://localhost:3000/admin.html`

## Данные для входа по умолчанию

Логин: `admin`  
Пароль: `admin123`

Перед публикацией в интернете обязательно поменяйте пароль и номер WhatsApp в `server.js` (или вынесите их в переменные окружения).

```js
const WHATSAPP_NUMBER = '992900000000';
const ADMIN_USER = 'admin';
const ADMIN_PASSWORD = 'admin123';
```

Номер WhatsApp указывается в международном формате без `+`, пробелов и скобок.

## Важно

Папка `data` создаётся сервером автоматически при первом запуске. Загруженные фотографии сохраняются в `uploads`.
