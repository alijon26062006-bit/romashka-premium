# Romashka Premium Flower Shop

Премиальный интернет-магазин цветов, созданный для продаж, быстрого оформления заказов и удобного управления каталогом. Проект подходит для локального запуска, размещения на сервере и дальнейшей продажи как готового коммерческого решения.

## Краткое описание для GitHub / продающего текста

Romashka Premium — современный интернет-магазин цветов с роскошным дизайном, удобной корзиной, WhatsApp-оформлением заказов и административной панелью для управления каталогом. Проект разработан под продажу и размещение на сервере, с готовым UI, API, каталогом товаров и возможностью быстро адаптировать под реальный бизнес.

## Что уже реализовано

- Премиальный дизайн главной страницы и адаптивная верстка
- Каталог товаров с категориями и фильтрацией
- Карточки товаров и отдельная страница продукта
- Корзина с количеством, суммой и удалением товаров
- Быстрое оформление заказа через WhatsApp
- Поиск по каталогу
- Плавающая кнопка WhatsApp для конверсии
- Админ-панель для добавления, редактирования и удаления товаров
- Загрузка изображений в формате JPG / PNG / WEBP до 8 МБ
- Сохранение данных в JSON-файле и работа через Express API
- Готовая структура проекта для запуска на сервере

## Технологии

- Node.js
- Express
- Multer
- HTML / CSS / JavaScript
- JSON для хранения каталога

## Запуск

```bash
npm install
npm start
```

После запуска проект будет доступен по адресу:
- Сайт: http://localhost:3000
- Админ-панель: http://localhost:3000/admin.html

## Почему этот проект стоит покупать / использовать

- Готовый коммерческий проект, а не пустой шаблон
- Есть полноценный продающий интерфейс и современная визуальная подача
- Заказ оформляется быстро через WhatsApp, что повышает конверсию
- В админке можно управлять каталогом без знания программирования
- Проект легко масштабировать, дополнять и адаптировать под другой цветочный бизнес
- Готовая архитектура позволяет быстро запустить на сервере и начать работу

## Важно для продакшна

- Смените логин, пароль и номер WhatsApp
- Настройте домен и сервер
- Проверьте изображения и цены
- Подготовьте уникальные товары под ваш бизнес

## Структура проекта

- `server.js` — основной сервер и API
- `public/` — фронтенд сайта
- `data/products.json` — каталог товаров
- `uploads/` — загруженные изображения
